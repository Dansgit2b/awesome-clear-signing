# Contributing to Awesome Clear Signing

Thanks for helping curate the best resources for **Clear Signing** on Ethereum & the EVM!

## What belongs here

Resources that help make transaction and message signing **human‑readable** on Ethereum/EVM:

- Standards & specifications (ERC‑7730, EIP‑712, EIP‑191, ERC‑4337, EIP‑7702, transaction types…)
- Tools to build, validate, preview, or audit ERC‑7730 descriptors
- Registries and contract‑metadata sources
- Wallets and platforms that render clear‑signing intent
- Security / simulation layers that complement clear signing
- Libraries, SDKs, articles, talks, and learning material

## What does **not** belong here

- Generic crypto/wallet links with no clear‑signing angle
- Pure marketing pages, dead links, or paywalled content with no substance
- Duplicate entries — search first

## Formatting rules

- One entry per line, in the relevant section, alphabetical **or** most‑canonical first.
- Format: `**[Name](url)** — One‑line description. \`tag\``
- Tags: `spec`, `official`, `tool`, `wallet`, `security`, `reference`, `article`, `community`.
- Prefer primary sources (the spec, the repo, the official docs) over blog reposts.
- Descriptions: factual, ≤ ~120 chars, no hype ("blazing‑fast", "revolutionary").
- Add new entries to the [Contents](README.md#contents) table of contents if you add a section.

## Submitting

1. Fork and create a branch.
2. Make your change; run any available markdown linter.
3. Open a PR describing **why** the resource is valuable for clear signing.

> Submitting a descriptor for a **real deployed contract**? Send it to the
> [ethereum/clear-signing-erc7730-registry](https://github.com/ethereum/clear-signing-erc7730-registry),
> not this list.
